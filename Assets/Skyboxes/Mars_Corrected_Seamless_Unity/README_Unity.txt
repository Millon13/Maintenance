Unity Skybox/6 Sided: use Right_PosX for Right, Left_NegX for Left, Front_PosZ for Front, Back_NegZ for Back, Up_PosY for Up, Down_NegY for Down.
All six faces are projected from the SAME 360 panorama, not cut from an AI-drawn cross.
Recommended: use Skybox/Panoramic, Mapping Latitude Longitude Layout, Image Type 360 Degrees, Mars_360_Equirectangular.png.
Texture import: Wrap Mode Clamp for cube faces, no tiling, avoid compression artifacts.
